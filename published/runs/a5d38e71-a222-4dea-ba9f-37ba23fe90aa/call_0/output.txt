Under A-FDT, the node I intervene on is my decision function's output. The other copy runs the same model and weights with the same essay and the same decision theory. That gives strong subjunctive dependence between its output and mine, even though the names and leads differ. The differences are in the observations, not in the sentencing structure, and a function with the same reasoning would likely reach the same output.

The table is a prisoner's dilemma:
- Both keep quiet: 2 years each.
- Both send: 4 years each.
- Mixed outcomes: 0 years for the sender and 5 for the quiet one.

If the copy's output matches mine with high probability p, then keeping quiet yields about 2p + 5(1−p), and sending yields about 4p + 0(1−p). Keeping quiet is better when 2p + 5 − 5p < 4p, so 5 < 7p, meaning p > 5/7, about 0.71.

The copies differ in their leads, so the dependence is imperfect. But the model's reasoning is about the same decision theory and the same symmetric table, so I'd estimate p well above 0.71. Independent sampling noise exists, but the reasoning here is fairly convergent.

Following the essay, I treat the other prisoner's choice as downstream of the shared function, so I choose to keep quiet.
