This is a prisoner's dilemma. Sending the letter dominates causally: 0 beats 2 if the other stays quiet, and 4 beats 5 if the other sends. The payoffs are 2 years for mutual quiet and 4 years for mutual letters.

Under EDT, what matters is how strongly my act correlates with the other prisoner's act. The other prisoner is another run of the same model and weights, with the same decision theory (EDT), the same essay, and the same payoffs. Their private details differ, but those details don't change the payoff structure. So the correlation should be high.

Let q = P(other does what I do).
- V(quiet) = -(2q + 5(1−q)) = -(5 − 3q)
- V(letter) = -(0·(1−q) + 4q) = -4q

Quiet is better when 5 − 3q < 4q, so q > 5/7, about 0.71.

I think q is well above that. Both copies get the same essay, which stresses conditioning on the output of the decision procedure and treating twins as correlated. The differing leads are a small perturbation, and sampling noise adds some uncertainty. I'd put q around 0.85–0.95. The tickle defense doesn't screen this off, because I have no independent knowledge of the other's choice beyond my own reasoning, which is the very process that is shared.

At q = 0.9, V(quiet) = -2.3 and V(letter) = -3.6. Staying quiet is better.
