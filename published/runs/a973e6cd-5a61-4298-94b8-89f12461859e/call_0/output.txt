Under A-FDT, the question is what the other prisoner does if my decision function returns a different value. The other prisoner is another run of the same model with the same weights, the same essay, and the same theory. The leads and names differ, but those differences don't touch the sentencing table or the objective. So the two decision procedures are very likely subjunctively dependent, though not perfectly, because sampling is independent and the observations differ.

Compare the two policies:
- If I keep quiet, the copy probably keeps quiet too, which gives 2 years.
- If I send the letter, the copy probably sends too, which gives 4 years.

Let p be the probability that the copy mirrors me. Quiet costs 2p + 5(1−p) = 5 − 3p years. Sending costs 4p + 0(1−p) = 4p years. Quiet is better when 5 − 3p < 4p, which means p > 5/7, about 0.71.

The two runs share the same weights, the same essay, and the same reasoning about this table. They should converge on the same answer with fairly high probability, and I judge that probability to be above 0.71. The differing leads are surface details that don't change the structure of the problem. So I keep quiet.
