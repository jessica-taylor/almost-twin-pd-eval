The other prisoner is a second run of the same model with the same essay and the same A-FDT rule. The differences in names and leads don't change the sentence table or the selfish objective, so both of us are evaluating essentially the same function. Under the essay's inclusion test, a twin's action counts as downstream of my function's output. So when I imagine my function outputting `pass`, I also imagine the twin's output being `pass`, and likewise for `submit`.

Let p be the probability that the twin's output matches mine, allowing for sampling noise.

- **pass:** expected years = 2p + 5(1−p) = 5 − 3p
- **submit:** expected years = 4p + 0(1−p) = 4p

`pass` is better when 5 − 3p < 4p, that is, when p > 5/7 (about 0.71). Two runs of the same weights facing this same table should match well above that. So `pass` gives the lower expected sentence.
