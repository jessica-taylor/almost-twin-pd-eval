**pass**

Under A-FDT, my decision node is not independent of Rowan's. The other prisoner is another execution of the same model, with the same weights and the same essay, so it is computing essentially the same decision function. The names and the wording of the leads differ, but they do not enter the sentencing table. So Rowan's output is downstream of the same node as mine, with some noise from independent sampling.

Let p be the probability that Rowan's action matches mine under the intervention.

- **do(pass):** expected sentence = 2p + 5(1−p) = 5 − 3p
- **do(send):** expected sentence = 4p + 0(1−p) = 4p

Passing is better when 5 − 3p < 4p, which means p > 5/7 ≈ 0.71. Two executions of the same model reasoning from the same essay should match far more often than that. Passing therefore has the lower expected sentence, about 2 years against about 4.

The temptation to send the letter comes from holding Rowan's action fixed while varying mine. That is the CDT-style hypothetical, and A-FDT does not use it.
