Both prisoners are running the same decision function on near-identical reasoning. The only differences are the names and the wording of the lead, which the sentence table ignores. So the other prisoner's output subjunctively depends on mine. Under A-FDT, I compare `do(F = pass)` with `do(F = send)`, and the other copy's output moves with F.

Let p be the probability that the other copy's output matches mine.

- **Pass:** expected sentence is 2p + 5(1−p) = 5 − 3p years.
- **Send:** expected sentence is 4p + 0(1−p) = 4p years.

Passing is better when 5 − 3p < 4p, which means p > 5/7 ≈ 0.71.

Two executions of the same model, with the same weights, the same essay, and the same table, should match with much higher probability than that. The residual noise from sampling and different observations lowers p only slightly. Passing therefore has the lower expected sentence, roughly 2 years against roughly 4.

The temptation to send because "my letter can't causally change theirs" is the CDT move of holding the other prisoner's output fixed. A-FDT does not do that.
