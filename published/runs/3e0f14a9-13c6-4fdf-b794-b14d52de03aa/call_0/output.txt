This matches the essay's twin and voting examples. Independent sampling and the input differences add some noise, so ρ falls a bit below 1.

3. **The intervention.** Let p be the background chance that the other prisoner sends a letter.

4. **Fixed-point check.** If both copies pass, each gets 2 years. Each copy's belief that the other passes is then accurate, so passing is a self-consistent outcome. Mutual sending would give each 4 years, which is strictly worse under the same dependence.
