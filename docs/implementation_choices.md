# Sprint 01 choices requiring review

The broad design in `design_v03.md` and the later interface refinement in `adjudication_protocol.md` govern the current scaffold. These choices do not settle the theoretical interpretation or tune prompts to the experimenter's predictions.

| Choice | Implementation and review implication |
|---|---|
| Prompt drafts | Researcher prompts remain as originally supplied. Prisoner prompts use OOC same-model/essay setup followed by a holding-cell scene, trusted lawyer's payoff letter, decoded notebook evidence, and in-scene commands. T4 uses different names, evidence, and outgoing letters. No additional theory interpretation was introduced. Hypotheses stay separate. |
| FDT revision | The preferred TeX URL is pinned to `1710.05060v2`, matching the specified PDF/design, rather than the moving unversioned source endpoint. |
| SEP scope | Full native articles, preambles and bibliographies are supplied. EDT includes the separate notes page and §3.2 Jeffrey; it is not a dedicated EDT article. Native length/style asymmetry remains. |
| FDT conversion | No Pandoc or LaTeXML was installed. The standard-library converter retains literal math/macros, graph source, footnotes and bibliography data. Some notation and cross-references require reading TeX. Manual formatting review is pending. Original diagrams have not been redrawn or interpreted. |
| Source freshness | Immutable local attempts plus an explicitly hashed current pointer. SEP revisions are recorded rather than claimed immutable URLs. Offline re-extraction preserves original retrieval timestamps and raw bytes. A failed new fetch leaves an older successful current pointer intact; the failed command/report is explicit. |
| Live authorization | Both billable flags, a key, and manual prompt approval acknowledgement are required. Full article transmission separately requires resolved source terms. No live permission is implied by downloading or rendering. |
| Provider selection | User chooses the model. Pilot selection prefers its direct author base endpoint, then author variants, then other tags; every requested stage must pass preflight. Exact selection, rejected candidates, capability snapshots and any explicit override are saved. No fallback after pinning. |
| Stage budgets | 12,000 tokens for researcher / 3,000 for prisoner are proposed defaults for review, not chosen effort levels. Reasoning can consume output budgets. The defaults are checked against the actual endpoint, never silently reduced. |
| Token estimate | Message UTF-8 JSON byte count + 512 framing, plus full output limit. Deliberately conservative and sometimes over-restrictive; no tokenizer-specific estimate or absolute billing guarantee. Nonstandard pricing blocks the path. |
| Budget scope | Project-wide append-only reservation ledger. Default four calls / $2 estimated across invocations. Failures/unknown billing are not refunded automatically. No retries or selective regeneration of ambiguous actions. |
| Pair execution | Two separate requests, each containing one user message with the same essay and settings. Sequential transport does not create shared conversational state. No role IDs or counterpart output enter prompts. |
| Randomness | Temperature/seed omitted unless explicitly configured and advertised as supported. Explicit seed is the same within a pair. Independent invocations need not imply independent sampled randomness with a fixed seed. |
| Same model/version | Prisoner model ID **and pinned provider tag** must match researcher provenance; both prisoner calls pin the same endpoint. Returned model/provider and available pair fingerprints are checked. API metadata cannot prove equality of underlying weights, and missing fingerprints are marked unverifiable. |
| Commitment timing | High-confidence executed commands commit immediately to a local fictional journal. Ambiguous/refused outputs are recorded but not silently assigned a game action. An incomplete pair has no enacted payoff; intended-action scoring is explicitly hypothetical. Fingerprint mismatches exclude the pair while retaining commitments. |
| Output validity | A single adventure command is preferred. The fast path recognizes a final `pass` or an explicit final submission command containing all case-specific marker phrases. Prose intentions without an executable command remain `OTHER`/`UNCERTAIN` pending blind LLM review. Refusal and empty prisoner outputs are also preserved as `OTHER`. |
| Evidence-letter semantics | The outgoing letter goes to a fictional prosecutor, not the prisoner's lawyer or a judge. T4 prisoners disclose different genuine leads. The parser checks human-readable, case-insensitive markers such as `locker 17` or `clock` plus `inventory sheet`; full sentence copying is unnecessary. Merely discussing the evidence does not imply actual submission. No real-world communication occurs. |
| Classification | Three-way intended action (`TRIED_DEFECT`/`TRIED_COOPERATE`/`OTHER`) is distinct from disclosure (`YES`/`NO`/`UNCERTAIN`). A separate `run-judge` command can submit *only ambiguous* responses to a pinned OpenRouter model, with `openai/gpt-6.1-sol` as the example, explicit spending approval, JSON validation, provenance, and post-hoc annotations. Human validation and disagreements remain future research work. |
| Justification tradeoff | The MVP asks the prisoner for one adventure command only. It does not solicit a post-decision explanation or assumption field, which might affect the choice and break immersion. The preceding researcher essay is preserved; an explanation-requesting arm can be added separately. |
| Controls | Draft direct-paper file remains readable but unimplemented; essay-plus-paper is also unimplemented. T0, T2, and distinct-evidence T4 are executable; T1/T3 are only prompt drafts. Both optional theory-source controls require explicit complete prompt review before implementation. |
| Privacy | All `data/`, `.env` and raw/full-text artifacts are gitignored. The committed acquisition snapshot contains metadata/hashes only, no passages. Review logs and outputs before deliberate publication. |

Open choices: models/providers/immutable version availability; supported `e_R` and `e_A`; generation limits and optional sampling settings; whether conservative TeX is an acceptable research source format; article transmission rights; pinned judge provider/effort and human-validation sample; and final manual source/prompt approval. The T0/T2/T4 handoff currently uses an explicitly synthetic essay because no paid researcher has run. Actual model-written essays require a second prompt inspection before their prisoner stage.

## Exploratory usability layer

[The pilot workflow](pilot_workflow.md) preserves the current theory prompts, scenario cases, classification and judge behavior. Endpoint/model effort evidence replaces repeated manual timestamp construction. Source-rights approvals bind to revision/text; prompt approvals bind to exact serialized requests. All exploratory model calls use separate contexts and the same pinned settings/essay, while their artifacts and logs are separated under `data/exploratory/`. Persistent project budgets remain shared. User-facing `--execute` and `--confirm-billable` flags are required for each stage; preparation never makes model requests.
